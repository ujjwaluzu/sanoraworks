# Project concept artwork

Generated on 17 November 2026 with the built-in image generation tool. These images illustrate planned interfaces for projects in development; they are not screenshots of released software. The same four artworks are used on homepage and directory cards and at larger size inside project detail previews.

## Assets

Final project images live in `public/projects/`. Each project has a `-concept.webp` version (1536 x 1024) and a `-concept-640.webp` card version (640 x 427). The component uses explicit dimensions, descriptive alternative text, lazy loading, and static WebP delivery, keeping images independent of a runtime optimisation service.

The original generated PNGs are preserved under the local, ignored `artifacts/project-artwork/source/` directory. Only the optimised WebP assets and this prompt record are intended for version control. Private project PDFs remain excluded.

## Art direction

Restrained, front-facing interface studies with a warm paper background, navy navigation, cobalt actions, readable typography, deliberate spacing, and workflow-specific details. No stock devices, floating UI fragments, decorative 3D objects, or neon effects.
