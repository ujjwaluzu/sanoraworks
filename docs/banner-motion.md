# Banner motion

Figure-sized, server-rendered SVG, using the Anatomy skill's projection and
four-tone solid primitives. A desktop computer and a miniature DNS test bench
share a grounded base. Light travels over etched circuit traces from the browser
to the resolver, then between the resolver and each nameserver, and back to the
browser. The root and TLD return referrals; only the authoritative server returns
the example address. This is an illustrative uncached lookup, not a live request.

Parts: four square rubber feet, beveled base, perimeter groove, four corner
fasteners; monitor plinth, pedestal, housing, bezel, glass, screen reflection,
disk slot, power switch, four side ventilation slots; keyboard tray, recessed
well, 24 individual keycaps, spacebar; resolver chassis, cover, front panel,
network port, three vents, activity light; rack base, two uprights, top crossbar,
three server blades, six mounting ears, three network ports, three lights,
nine cooling slots; four etched signal routes and their eight terminal pads.

The original PNG is never rewritten. Three SVG clips separate its two orbit
curves from its SW letters. The curves begin as a joined, compact orbit, then
separate and settle into their original positions as the letters appear.
The masthead and downloadable brand assets remain unchanged.

One twelve-second Web Animations timeline drives the orbit, DNS signals, lights,
screen and captions. Visibility, tab state and the single pause button suspend
every track together. Reduced motion and JavaScript-disabled rendering show the
finished original logo and a completed DNS lookup.

DNS sequence reference: https://www.cloudflare.com/learning/dns/what-is-dns/

Anatomy primitives are vendored in `src/lib/illustrations/iso-kit.ts`; the
original MIT notice is included alongside them.
