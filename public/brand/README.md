# SanoraWorks identity

Original static orbital S emblem with a globe and square satellite. Default assets use navy #002f49 and teal #006666. Light variants are for dark teal surfaces; monochrome variants use #111111. SVGs scale without rasterization. Keep the full emblem clear of surrounding content and use the simplified favicon below 24px.

- sanoraworks-wordmark.svg: combined wordmark and emblem, 390 x 72 viewBox.
- sanoraworks-emblem.svg: standalone emblem, 80 x 64 viewBox.
- -light and -mono files: matching variants.
- sanoraworks-favicon.svg: simplified 32 x 32 favicon, suitable at 16px.
- /apple-icon: generated 180 x 180 PNG.
- /opengraph-image: generated 1200 x 630 PNG.

All wordmark lettering, emblems, and favicons are outlined vector paths with no font dependencies. The website uses native text for accessible, crisp masthead lettering.
